# Super Bowl 60 Prop Bet Bingo Card Generator

This is a fork of [cartern206/superbowl](https://github.com/cartern206/superbowl) updated with new prop bets for the 2026 Super Bowl.

With anticipation for the big game, this website generates Super Bowl bingo cards with updated prop bets that you can print and bring to your Super Bowl Party. If you want something fun for everyone, check it out at **https://jerbri.github.io/superbowl/**
